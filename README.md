# 3D Motion Lab

두 대의 스마트폰으로 동시에 촬영하고, 플래시 신호로 영상을 맞춘 뒤 3차원 운동을 분석하기 위한 새 웹앱이다.

## 현재 단계

- 선생님/스마트폰 진입 화면
- 촬영 방 UI 첫 설계
- Firebase 연결을 위한 환경 변수 자리 준비
- 반응형 화면

## 실행

```bash
pnpm install
pnpm dev
```

## 이어서 만들 기능

1. Firebase 촬영 방과 실시간 준비 상태
2. 스마트폰 카메라 A/B 연결
3. 공동 촬영 명령과 플래시 동기화
4. 영상 업로드
5. 기존 3차원 분석 기능 이식
