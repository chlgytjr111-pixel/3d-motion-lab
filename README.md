# 3D Motion Lab

두 대의 스마트폰으로 동시에 촬영하고, 플래시 신호로 영상을 맞춘 뒤 3차원 운동을 분석하기 위한 새 웹앱이다.

## 현재 단계

- Firebase 촬영 방 생성과 6자리 코드 입장
- 선생님/카메라 세션의 새로고침 복구
- 기존 방 관리 화면 재입장과 방 영구 삭제
- 스마트폰 카메라 A/B 자동 배정과 준비 상태 동기화
- 선생님이 FPS, 셔터 기록값, 촬영 시간을 지정
- 지원 기기에서 FPS와 수동 노출 제약 적용 시도 및 실제 적용값 표시
- Firebase 서버 시각 기준 5초 카운트다운과 자동 녹화
- 녹화 영상 미리보기, 기기 저장, 기본 밝기 급상승(플래시 후보) 검출
- 촬영을 건너뛰고 보유한 사진·영상으로 바로 분석
- Tracker형 한 화면 분석 작업대: 좌우 영상, 도구 아이콘, 안내 팝업, 내부 패널
- 7개 이상 기준점 카메라 보정, 수동·색상 자동 추적, 두 물체 분석
- 3차원 궤적, 위치·속도·가속도 그래프, CSV 내려받기
- 촬영 방에 분석 결과 수치를 Firebase로 저장
- 모바일 반응형 화면

## 실행

```bash
pnpm install
pnpm dev
```

분석 화면은 `/analyze`에서 바로 열 수 있다. `pnpm build`를 실행하면
`analyzer-src/legacy-gas`의 기존 계산 코드를 브라우저용 정적 파일로 나누어 생성한다.

## 이어서 만들 기능

1. Firebase Storage 또는 별도 영상 저장 서버 연결
2. 두 영상의 플래시 프레임 자동 정렬
3. 별도 OpenCV 분석 서버를 통한 대용량·다중 점 추적 가속
4. 네이티브 촬영 앱을 통한 확실한 120fps와 수동 셔터 제어
